# Persiapan Launching TA 2026/2027

Target eksekusi rollover: **Juni-Juli 2026**.

## Fase 1: Finalisasi SPMB ⏳
- [ ] Tombol "Tutup Pendaftaran" + arsip pendaftar (status final)
- [ ] Bulk konversi pendaftar **diterima** → siswa kelas 7 TA 2026/2027
  - Auto-assign ke kelas 7 (multi-rombel, ratakan/manual)
  - Generate akun siswa massal (`[NIS]@siswa.mts`)
- [ ] Notifikasi WA "Selamat datang" ke ortu pendaftar diterima
- [ ] Statistik final SPMB (diterima/ditolak/cadangan)

## Fase 2: Tutup Buku Keuangan TA 2025/2026
- [ ] Tabel baru `laporan_tahunan` (immutable snapshot)
- [ ] Halaman "Tutup Buku" — ringkasan pemasukan, pengeluaran, saldo, tunggakan
- [ ] Export PDF + Excel arsip resmi (TTD Bendahara + Kepala)
- [ ] Daftar siswa nunggak → otomatis "Tunggakan Lama" di TA baru

## Fase 3: Wizard Rollover TA (5 langkah, dengan dry-run preview)
1. Buat TA 2026/2027 Ganjil + set aktif
2. Naik kelas otomatis (7→8, 8→9) via `siswa_riwayat`
3. Luluskan kelas 9 → pindah ke `alumni`
4. Tempatkan siswa baru hasil SPMB ke kelas 7
5. Reset jenis tagihan + generate tagihan SPP TA baru

**WAJIB**: Mode preview (dry-run) sebelum commit. Tampilkan tabel "siapa naik, siapa lulus, siapa tinggal kelas".
